06. Guias de publicação
- Nova funcionalidade
- Utiliza a interface 03 onde cada opção é um arquivo .md dentro da pasta /.lumina/guides
- Ao selecionar uma opção, vamos usar o bubbles (https://github.com/charmbracelet/bubbles) um viewport com o conteúdo em markdown e "rolavel" para mostrar o conteúdo.
- O Lumina Tools não cria esses arquivos, somente verifica se na pasta de instalação (onde estão as configurações) existe a pasta guides
- O Lumina deve verificar a existência dessa pasta sempre que for iniciado ou atualizado/instalado, se não existir, cria. Se existir, não faz nada
